📚 Library Management

Hệ thống quản lý thư viện hiện đại và dễ sử dụng

✨ Tính năng chính

📖 Quản lý sách

Quản lý thông tin chi tiết về sách bao gồm tên, tác giả, ISBN, nhà xuất bản, số trang và thể loại.

🔄 Workflow mượn/trả

Hệ thống theo dõi trạng thái sách: Có sẵn, Đã mượn, Bảo trì, Mất. Dễ dàng quản lý việc mượn và trả sách.

👥 Quản lý người mượn

Liên kết với hệ thống Partners để quản lý thông tin người mượn sách.

🔍 Tìm kiếm và lọc

Tìm kiếm nhanh theo tên sách, tác giả, ISBN. Lọc theo trạng thái, thể loại.

📊 Theo dõi thay đổi

Tích hợp chatter để theo dõi lịch sử thay đổi và ghi chú.

🖼️ Ảnh bìa sách

Hỗ trợ upload và hiển thị ảnh bìa sách.

🚀 Cách sử dụng

  1. Vào menu Thư viện
  2. Click Quản lý sách
  3. Tạo sách mới bằng nút Create
  4. Sử dụng các nút Mượn sách/Trả sách để quản lý workflow

📋 Yêu cầu hệ thống

  • Odoo 18.0+
  • Module: base, mail
